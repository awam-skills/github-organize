# Excel 列约定与人工处理

在导出、解读或按表执行 `process_excel.py` 时阅读本文件。实现：`scripts/export_report.py`、`scripts/process_excel.py`。

## 仓库表列

仓库名、完整名、类型、可见性、是否归档、主语言、Stars、描述、创建时间、最后推送、距今推送天数、上游仓库、ahead、behind、本人提交、处理分类、建议、URL、**人工处理**、**处理结果**、**进一步建议**

## 星标项目表列

仓库、Owner、主语言、Topics、描述、上游 Stars、是否归档、是否 Fork、最后推送、距今推送天数、星标时间、距今星标天数、处理分类、建议归入 List、建议、URL、**人工处理**、**处理结果**、**进一步建议**

## 工作流与密钥表列

仓库、是否归档、有 Workflow、Workflow 数、近期失败运行数、失败工作流名、Secrets 数、孤儿 Secrets 数、孤儿列表、CodeQL 状态、处理分类、建议、备注/错误、URL、**人工处理**、**处理结果**、**进一步建议**

未启用 hygiene 时该表可为空，汇总会注明未启用。

## 人工处理列

| 取值 | 含义 |
|------|------|
| （空）或 不处理 | `process_excel.py` 跳过该行（导出默认「不处理」；用户也可清空表示不处理） |
| 按照建议 | 按「处理分类」映射可自动动作（删 fork 时**含**星标上游 / 归档 / unstar 等） |
| 其它任意文字 | 「其他处理方式」；脚本归类意图，能自动则执行，否则写入「进一步建议」供 Agent 分析 |

仓库表常见可识别文字：

| 文字 | 自动动作 |
|------|----------|
| 删除 / 删掉 / delete | 删仓，**不**星标上游 |
| 删除并标星（含「标星」「打星」「star」） | 星标上游 + 删 fork |
| 归档 / archive | 归档 |
| 星标上游 / 打星上游 | 仅星标上游 |
| 取消星标 / unstar | 取消星标（多用于星标表） |

`process_excel.py` 行为补充：

- 数据表**缺少「人工处理」列**：跳过该表，摘要 `sheet_skipped` 记录原因，其它表照常处理
- 「按照建议」的删除类仍会星标上游；自由填写的「删除」不会
- 工作流与密钥表：任意人工处理文字均**不自动**删密钥/改 CI；写入进一步建议

导出时「处理结果」「进一步建议」为空；执行 `process_excel.py` 后回写。

## 按表可自动映射（摘要）

| 表 | 条件 / 人工处理文字 | 自动动作 |
|----|---------------------|----------|
| 仓库 | 「按照建议」+ Fork 建议删除类 | 星标上游 + 删 fork |
| 仓库 | 「按照建议」+ 自有建议归档类 | 归档 |
| 仓库 | **删除** / 删掉 / delete | 删仓；**不**星标上游 |
| 仓库 | **删除并标星**（文中含标星/打星/star） | 星标上游 + 删 fork |
| 仓库 | **归档** / archive | 归档 |
| 仓库 | 星标上游 / 打星上游 | 仅星标上游 |
| 星标 | 「按照建议」+ 建议取消星标类；或「取消星标」 | unstar |
| 工作流与密钥 | 任意 | **不自动**删密钥/改 CI；写入进一步建议 |
